**Recovery Protocol: Unauthorized Asset Movement in Coinbase Wallet**

* **Token Type:** Solana (SOL)
* **Wallet Platform:** Coinbase Wallet (mobile)
* **Issue Type:** Unauthorized outgoing transaction without secret phrase disclosure
* **Suspected Entry Vector:** Residual contract approval, scam token interaction, or platform-side exposure

---

### Immediate Action Plan

1. **Secure a New Wallet**

   * Use Coinbase Wallet or MetaMask (desktop/mobile)
   * Generate a fresh recovery phrase — never reuse previous ones
   * Store the phrase safely and offline (paper, encrypted USB, etc.)

2. **Transfer Safe Assets Only**

   * Manually verify each asset using [Solscan](https://solscan.io)
   * Transfer only legitimate, recognized tokens to your new wallet
   * Avoid all unsolicited or unrecognized tokens and NFTs

3. **Revoke Malicious Permissions**

   * Recommended tool: [Step Finance Token Management](https://app.step.finance/token-management)
   * Mobile users: open Coinbase Wallet settings → Connected Apps → Remove suspicious access
   * For enhanced safety: consider installing Blowfish or Solana Shield extensions

4. **Report & Log the Incident**

   * Submit a formal report through [Chainabuse](https://www.chainabuse.com)

     * Include your address, attacker’s address, token details, and event timestamp
     * Add screenshots and a clear description of the issue
   * Contact [Coinbase Help Center](https://help.coinbase.com/) for additional reporting

5. **Long-Term Recommendations**

   * **Use a Hardware Wallet**: Ledger Nano S or X for storing high-value assets
   * Interact only with verified dApps (check via platforms like [DeFi Llama](https://defillama.com))
   * Stay up to date with wallet and browser security tools
